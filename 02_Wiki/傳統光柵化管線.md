# 傳統光柵化管線

## 一句話白話定義
圖形渲染管線（Graphics Pipeline）就像一條工廠流水線，把 3D 空間中的三角形頂點座標一步步轉換、投影，最後變成螢幕上 2D 的彩色像素（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。

## 核心機制與重點
- **兩大核心任務**：第一部分把 3D 座標轉換為 2D 座標；第二部分把精確的 2D 座標近似轉換為受螢幕解析度限制的彩色 2D 像素（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。
- **關鍵渲染階段（依序執行）**：
  1. **頂點輸入與緩衝管理**：以 3D 座標陣列定義頂點，透過 **VBO（頂點緩衝對象）** 一次性將大量頂點送到 GPU 顯存（減少 CPU 到 GPU 的慢速傳輸），並用 **VAO** 記錄屬性解析方式、用 **EBO（索引緩衝對象）** 避免共用頂點重複儲存（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。
  2. **頂點著色器（Vertex Shader）**：可程式化階段（以 GLSL 撰寫），接收單一頂點並進行座標變換，將可見區域映射至 $-1.0$ 到 $1.0$ 的**標準化設備座標（NDC）**（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。
  3. **圖元裝配（Primitive Assembly）**：依指定圖元類型（如 `GL_TRIANGLES`）將頂點連接成三角形（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。
  4. **光柵化（Rasterization）與裁切（Clipping）**：丟棄視野外的像素，將三角形映射為螢幕上對應的離散「片段（Fragment，渲染單一像素所需的完整資料）」（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。
  5. **片段著色器（Fragment Shader）**：可程式化階段，結合光照、陰影與材質資訊計算每個像素的最終 RGBA 顏色（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。
  6. **深度測試與混合（Alpha Test & Blending）**：依深度值（z 軸距離）丟棄被遮擋的像素，並依透明度（alpha）混合前後顏色（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。
- **為什麼以三角形為基礎**：管線的每個階段高度專一且天然適合 [[GPU平行運算]]，在現代 OpenGL 中開發者必須至少提供頂點與片段兩個著色器（來源：`01_原始資料/02_傳統光柵化渲染管線.md`）。

## 限制或觀點衝突
- **表面近似與光影限制**：傳統攝影測量產出的三角網格（Mesh）與貼圖擅長精確表達幾何表面（適合測量、CAD 與物理模擬），但在重現真實世界中隨視角變化的細微反光與高光（view-dependent effects）時，只能用近似方法處理，不如輻射場原生支援（來源：`01_原始資料/04_3DGS高斯潑濺核心概念.md`）。
