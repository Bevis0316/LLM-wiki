# GPU平行運算

## 一句話白話定義
GPU（圖形處理器）是專門為「同時處理海量重複小任務」打造的處理器，靠數千個較簡單的核心平行運作，讓螢幕上數百萬個像素能同時算出顏色（來源：`01_原始資料/01_GPU平行運算與CPU差異.md`）。

## 核心機制與重點
- **CPU vs. GPU 設計分工**：
  - **CPU（中央處理器）**：配置少量但強大的核心（消費級常見 4–64 核），主頻高（最高約 ~5 GHz）、具備較大快取（L1/L2/L3）與分支預測能力，採串行執行（取指 → 譯碼 → 執行 → 儲存），擅長需要高精度與複雜邏輯決策的通用任務，如作業系統管理與資料庫查詢（來源：`01_原始資料/01_GPU平行運算與CPU差異.md`）。
  - **GPU（圖形處理器）**：配置成千上萬個較小的核心，主頻較低（約 ~1–2 GHz），採 **SIMD（單指令多數據）** 平行模型，將相同指令同時套用到大量資料點上，並搭配高頻寬記憶體（GDDR6、HBM）追求極致資料吞吐量（來源：`01_原始資料/01_GPU平行運算與CPU差異.md`）。
- **為什麼 3D 渲染高度依賴 GPU**：
  - 畫面渲染時，GPU 可將每個像素分配給獨立核心同時計算顏色；在 [[傳統光柵化管線]] 中，成千上萬的小核心會為每個階段平行執行小型程式——**著色器（Shader）**，大幅節省 CPU 時間（來源：`01_原始資料/01_GPU平行運算與CPU差異.md`、`01_原始資料/02_傳統光柵化渲染管線.md`）。
  - 現代 [[3DGS高斯潑濺]] 也正是因為將 3D 高斯體投影與混合轉化為 GPU 每秒可執行數十億次的光柵化平行運算，才實現即時渲染（來源：`01_原始資料/04_3DGS高斯潑濺核心概念.md`）。
- **延伸生態與演進**：GPU 透過 CUDA、ROCm 等軟體生態擴展到 AI 深度學習（如矩陣乘法與 Tensor Cores）與科學運算；但 GPU 無法取代 CPU，實務上常採「CPU 負責流程邏輯＋GPU 負責平行計算」的混合分工（來源：`01_原始資料/01_GPU平行運算與CPU差異.md`）。

## 限制或觀點衝突
- **功耗與成本取捨**：因核心密度高且記憶體頻寬需求大，高階 GPU 滿載功耗可達數百瓦，且價格遠高於一般 CPU（來源：`01_原始資料/01_GPU平行運算與CPU差異.md`）。
- **訓練 vs. 瀏覽的硬體門檻差異**：在 [[3DGS高斯潑濺]] 應用中，訓練場景仍需要現代消費級 GPU，但訓練完成後的即時瀏覽已可在手機、平板或一般筆電上運行（來源：`01_原始資料/04_3DGS高斯潑濺核心概念.md`）。
