# 三大3D表示法比較

## 一句話白話定義
三角網格（Mesh）、有號距離場（SDF）與 3D 高斯潑濺（3DGS）代表 3D 圖學的三種核心語言——分別擅長「互動建模」、「數學幾何」與「寫實場景重建」，實務上正走向彼此互補（來源：`01_原始資料/02_傳統光柵化渲染管線.md`、`01_原始資料/03_SDF與光線步進原理.md`、`01_原始資料/04_3DGS高斯潑濺核心概念.md`、`01_原始資料/05_三大3D表示法比較與限制.md`）。

## 核心機制與重點
| 比較維度 | 傳統三角網格（Mesh） | 有號距離場（SDF） | 3D 高斯潑濺（3DGS） |
| :--- | :--- | :--- | :--- |
| **資料本質** | 顯式頂點、索引與三角面片 | 隱式距離函數（解析公式或神經網路） | 數百萬個顯式 3D 高斯橢球（`.ply`/`.splat`） |
| **核心渲染機制** | 頂點變換 → 光柵化 → 片段著色 | Sphere Tracing（光線步進）或體積渲染 | 投影潑濺（Splatting）→ 深度排序 → $lpha$ 混合 |
| **即時渲染效能** | 極快（硬體原生光柵化管線） | 解析式可即時；神經 SDF 訓練與採樣較慢 | 極快（可即時運行於手機與 VR） |
| **幾何精度與細節** | 精確表達表面，適合測量與物理模擬 | 數學級平滑連續表面，支援布林與無限重複 | 照片級光影與反光極佳，但幾何易模糊或有浮點偽影 |
| **檔案 / 資源特性** | 依網格面數與貼圖大小而定 | 解析式極省空間（僅存公式）；神經式存網路權重 | 典型場景約數十至數百 MB |
| **最適用場景** | 遊戲、CAD/BIM、物理碰撞與精確測繪 | 程序化幾何、布林建模、高精準神經表面重建 | 實景掃描、街景漫遊、VR 紀錄與影視特效 |

（上表綜合整理自 `01_原始資料/02_傳統光柵化渲染管線.md`、`01_原始資料/03_SDF與光線步進原理.md`、`01_原始資料/04_3DGS高斯潑濺核心概念.md`、`01_原始資料/05_三大3D表示法比較與限制.md`）

- **現代融合解法：GSDF 雙分支架構**：
  為解決「3DGS 渲染快但幾何弱、神經 SDF 幾何準但訓練慢」的兩難，GSDF 論文提出雙分支互導架構（來源：`01_原始資料/05_三大3D表示法比較與限制.md`）：
  1. **GS → SDF（深度引導採樣）**：用高速 GS 分支渲染出的深度圖縮小 SDF 的光線採樣範圍，大幅加速收斂（相比 Neuralangelo 2 GPU 約 12 小時，GSDF 單 GPU 約 2 小時即達同等甚至更佳重建品質）。
  2. **SDF → GS（幾何感知密度控制）**：利用 SDF 零等值面引導高斯體在表面附近生長，並修剪遠離表面的漂浮偽影（floaters）。
  3. **GS ↔ SDF（雙向幾何監督）**：對齊兩分支的深度圖與法線圖；推論瀏覽時僅使用 GS 分支，保有原本的即時渲染速度（來源：`01_原始資料/05_三大3D表示法比較與限制.md`）。

## 限制或觀點衝突
- **單一表示法無法通吃所有任務**：工程與測繪領域（CAD/BIM、物理模擬）仍需精確表面幾何（Mesh 或 SDF）；視覺導覽與實景紀錄則以 3DGS 佔優，因此產業與學界正轉向「LiDAR／攝影測量＋3DGS」或「3DGS＋SDF（如 GSDF）」的混合管線（來源：`01_原始資料/04_3DGS高斯潑濺核心概念.md`、`01_原始資料/05_三大3D表示法比較與限制.md`）。
- **混合架構的現存瓶頸**：GSDF 雖同時提升渲染與重建指標，但加入 SDF 分支會拖慢整體訓練速度，且對透明／半透明物體與強烈室內反光變化仍表現受限（來源：`01_原始資料/05_三大3D表示法比較與限制.md`）。
